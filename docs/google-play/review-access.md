# Play reviewer access — draft, not live credentials

Reuse the isolated review architecture only after operator confirmation of its
current retention, expiry and Android compatibility. Create dedicated Play access;
do not publish or reuse the private Apple invitation implicitly.

Proposed reviewer instructions:

1. Open Settings. Paste the private review invitation in the setup field, review
   the gateway details, then explicitly enroll. The isolated review environment
   should approve this review grant automatically; verify that behavior first.
2. Connect using saved review access. No owner/admin permissions, personal data,
   VPN, payment or external account should be required for this isolated route.
3. In Talk, type a short question and Send. For voice, allow microphone access and
   ensure the selected English/Spanish on-device language model is installed.
   Tap record, wait for readiness, speak, Stop, review, then explicitly Send.
4. Accept gateway speech processing, choose the available voice and preview it.
   Review the conversation in History, background/reopen, and verify reconnect
   without automatic Send, microphone start or replay.

Known boundaries: supported Android on-device recognition is required for speech
input; typing remains available. No cloud recognition fallback. No Android Auto.
The isolated guest route excludes owner management and agent tools. Reviewer
access must remain available through the review window; an expired invitation
is not a valid app-access submission.

No actual Play enrollment or model request was made by this preparation.
