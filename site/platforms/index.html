Compatibility · Beta

Your phone.
Your choice of host.

Voxkin is an iPhone app for iOS 17 or later. Your OpenClaw gateway runs separately on a computer or server. The optional Voxkin plugin adds local English and Spanish speech and restricted, separately enrolled phone access.

Tested gateway targets: macOS on Apple Silicon, Ubuntu 24.04 x86_64 in containers, and native Windows 11 x64. These are tested beta configurations—not a guarantee for every operating-system version, processor, model provider or installation method.

Native Windows: no host patch

The Windows adapter lives in our plugin. It uses a public OpenClaw API, keeps restricted-phone tools disabled, and verifies terminal assistant text before returning it to the phone. macOS and Linux keep their existing dispatch path.

Windows gateway administrators must enable plugins.entries.voxkin-local.hooks.allowConversationAccess=true for the plugin to verify replies. This grants conversation-hook access to the plugin; its handler filters for the exact active run, agent and session. Unsupported or ambiguous output fails closed.

CarPlay

CarPlay voice conversations require iOS 26.4 or later and a compatible vehicle or head unit. CarPlay is included in beta build 12 and the 1.0 release candidate. Release packaging checks verified the scene configuration, background-audio mode and signed CarPlay entitlement. These checks do not establish compatibility with every vehicle, audio route or interruption scenario. Set up gateway access on your iPhone before driving.

Not yet qualified

  • Windows ARM, Linux ARM, Alpine/musl, Intel Macs and other host versions or model harnesses.
  • Every voice, every Bluetooth/audio route, all reconnect conditions or long-running unattended operation.
  • Android or a dedicated iPad, desktop or web client.

Offline voice-runtime tests mean synthesis worked without network access after models were installed. They do not mean conversations or cloud-configured model providers work offline. On-device dictation also depends on your iPhone and language support.
