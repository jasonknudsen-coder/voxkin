Voxkin Local adds optional offline English and Spanish voices and separately enrolled guest phones to your own OpenClaw gateway. It is not the mobile app, a hosted assistant, or a replacement for OpenClaw.

Voxkin Local 0.4.2

Security update: per-phone resource limits, safer owner setup codes, and an isolated local speech worker.

  • Download plugin 0.4.2 (.tgz) — source only, under 100 KB
  • Download SHA-256 checksum
  • Read the installation and upgrade guide

New owner QR codes require Voxkin iOS 1.0.1 or Android 0.2.20 or later. If the update is not yet available in your store, use manual in-app owner setup. Existing saved connections and guest invitations keep working. Always scan owner codes inside Voxkin, not the system camera.

Before you install

  1. Use an existing gateway you administer, with its supported Node runtime and Python 3.13 for local speech.
  2. Download the package and checksum into the same folder. On macOS verify with shasum -a 256 -c SHA256SUMS; on Linux use sha256sum -c SHA256SUMS. The guide includes Windows instructions.
  3. Review the included source, installation guide and third-party notices. Back up an existing installation before upgrading.
  4. Install through OpenClaw with openclaw plugins install ./voxkin-openclaw-local-voice-0.4.2.tgz --no-enable, then follow the guide for explicit setup, trust/capability review and activation.

--no-enable preserves existing enablement; it does not disable an already active plugin. Coordinate upgrades with other gateway users. Never replace your entire configuration with an example or share owner credentials with guests.

What is—and isn't—in the download

The package contains Apache-2.0 plugin source, installation instructions and dependency notices. No models, Python wheels, native binaries, private configuration or gateway credentials are included. Explicit setup downloads the upstream speech runtime separately. No background download occurs at gateway startup.

This release's actual local speech checks cover macOS Apple Silicon with Python 3.13. OpenClaw 2026.10.6 SDK integration and isolated package installation are verified; 2026.9.7 was the earlier tested host. Linux x86_64 and Windows x64 setup remain experimental: their earlier tests have not been rerun for this release's worker-isolation change. See the guide and historical testing matrix for boundaries.

Keep your gateway's normal authentication, TLS and network controls. Restricted phone access is conversation-only and requires owner approval. Local speech is optional; your existing default speech provider is not replaced.

Need help? Contact Voxkin support. Do not send tokens, QR credentials, or private conversations.
